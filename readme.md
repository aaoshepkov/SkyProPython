# Учебный проект. Курс Разработчик на Python, группа 49.0.

## Описание:

В рамках учебного проекта реализуется бэк-енд банковской системы.

Тестирование функций проекта производится с Pytest.

Тестовые модули находятся в папке tests, один тестовый модуль тестирует функции соответствующего модуля программы.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/aaoshepkov/SkyProPython.git
```

2. Установите poetry:
```
https://python-poetry.org/docs/#installing-with-the-official-installer
```

3. Установите зависимости:
```
poetry install
```


## Использование:

1. Логика находится в файле main.py
2. В модуле masks.py реализована логика маскировки номера карты или счета
3. В модуле processing.py реализована логика фильтрации по Статусу платежа и сортировки транзакций по дате.
4. В модуле widget.py реализована логика пользовательского ввода номера карты или номера счет и маскировки их через вызов модуля masks.py
5. В модуле generators.py реализована логика фильтрации транзакций по коду валюты, получения описания транзакции, генерации номера карты
